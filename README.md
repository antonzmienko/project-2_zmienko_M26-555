# primitive-db

Консольная база данных. Можно создавать, смотреть и удалять таблицы, а также выполнять CRUD-операции с данными. Структура таблиц сохраняется в файл `db_meta.json`, данные каждой таблицы — в отдельном JSON-файле в директории `data/`.

## Управление таблицами

Сборка и установка:

```bash
uv build
uv tool install --force dist/*.whl
```

Запуск:

```bash
database
```

Команды:

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу. Столбец `ID:int` добавляется автоматически, если его не указали.
- `list_tables` — показать список всех таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу (с подтверждением).
- `help` — показать справку.
- `exit` — выйти из программы.

Типы столбцов: `int`, `str`, `bool`.

Пример:

```text
$ database

***Процесс работы с таблицей***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

Общие команды:
<command> exit - выход из программы
<command> help - справочная информация

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: create_table users name:str
Ошибка валидации: Таблица "users" уже существует.

Введите команду: list_tables
- users

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.

Введите команду: drop_table products
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Ошибка валидации: Таблица "products" не существует.

Введите команду: exit
```

## CRUD-операции

Команды для работы с данными таблиц:

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — создать запись. Столбец `ID` заполняется автоматически.
- `select from <имя_таблицы>` — прочитать все записи.
- `select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи по условию.
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец> = <значение>` — обновить запись.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить запись (с подтверждением).
- `info <имя_таблицы>` — вывести информацию о таблице.

Строковые значения в условиях и в `values` указывайте в кавычках. Между `values` и `(` нужен пробел.

Пример:

```text
$ database

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: insert into users values ("Sergei", 28, true)
Функция insert выполнилась за 0.000 секунд.
Запись с ID=1 успешно добавлена в таблицу "users".

Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".

Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0

Введите команду: exit
```

## Декораторы и надёжность

В проекте используются декораторы и замыкания:

- **Обработка ошибок** (`handle_db_errors`) — централизованный перехват `FileNotFoundError`, `KeyError`, `ValueError` и других исключений при работе с таблицами. Сообщения об ошибках выводятся единообразно, без дублирования `try...except` в каждой функции.
- **Подтверждение действий** (`confirm_action`) — перед опасными операциями (`drop_table`, `delete`) запрашивается подтверждение: `Вы уверены, что хотите выполнить "..."? [y/n]:`. Операция выполняется только при ответе `y`, иначе отменяется.
- **Замер времени** (`log_time`) — для `insert` и `select` в консоль выводится время выполнения: `Функция <имя> выполнилась за X.XXX секунд.`
- **Кэширование** (`create_cacher`) — результаты одинаковых `select`-запросов кэшируются через замыкание.

Пример подтверждения и отмены удаления:

```text
Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```
